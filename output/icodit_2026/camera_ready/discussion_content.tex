\paragraph{Adaptation and retention are separate outcomes.} Measuring both on the same checkpoints separates patterns that a single score would merge. Under delay in HalfCheetah, the reactive controller adapted and lost clean performance; retained replay preserved its clean performance and kept part of the gain. The transformer lost clean performance without adapting. Under noise, the transformer kept both returns near their starting values, whereas the reactive controller lost both, far less so when half of each batch came from earlier clean experience. In HalfCheetah, every fault branch without replay also forfeited the improvement that continued clean training produced, so a branch that merely holds its starting return has still fallen behind. Ant shows the control's value in the other direction: its standing sources lost little to either fault and did not improve under clean training, so changes in its fault branches reflect continued training more than the faults.

\paragraph{Why the controllers differ.} The information available to each controller predicts an advantage for the transformer under both faults. Its context holds the last three commands needed to reconstruct the current state from the delayed reading, and a window of noisy readings that it could average; the reactive token holds one reading and the previous command. In HalfCheetah, the noise results agree with this prediction, but the delay results contradict it: only the reactive controller improved. We see four candidate explanations, none tested here. First, compensating for the delay requires the encoder to learn a new computation, and it learns only through critic regression, because the actor uses detached features. Second, continued training is relatively weaker for the transformer: each update trains 64 transitions, a sixteenth of the 1,024 per critic update in its source training, whereas the reactive controller trains on 64 transitions in both phases. Third, 5,000 updates at learning rate $10^{-4}$ may be too few to reorganize a representation that is adequate for clean sensing. Fourth, the controllers differ in capacity and initial returns (Table~\ref{tab:arch}). Separating these explanations requires matched ablations, such as a transformer restricted to one token or a reactive controller given stacked readings and commands.

\paragraph{Replay mixing.} Of the sixteen paired replay effects in the two tasks, only one had a negative mean: the HalfCheetah reactive controller's smaller delayed-sensing gain. The critic diagnostic is consistent with the target blending described in Sec.~\ref{sec:critic}. The source critics overvalued delayed histories relative to clean ones, anticipating only part of the return that the source policies lost under delay. Training on delayed data alone removed most of this value-bias gap; with clean experience mixed in, the gap stayed larger, and the reactive controller's residual on delayed data stayed higher. The transformer showed the same gap pattern but had no delayed-sensing gain to lose. Under noise, replay improved both of the reactive controller's returns while raising its residuals, so a larger held-out residual alone does not indicate a worse policy. In Ant, where the faults barely mattered, the gaps stayed near zero. A two-episode clean pool is a minimal form of rehearsal. In HalfCheetah, retained replay did not match the clean control's gains on clean data, and behavior-cloning or feature-preservation terms~\cite{clear,finetuneforget} could act differently.

\paragraph{Limitations.} The sources were trained with actuator perturbations and then warm-started; sources trained to convergence, or with sensor faults, may behave differently. The Ant sources stood rather than walked, so Ant tests the retention of a posture rather than of locomotion; we did not tune the source recipe after seeing this. Twenty thousand steps are 5\% of the source recipe's 400,000-step budget, and 5,000 updates are 5\% of its critic updates, so slower adaptation could still occur. We used one severity per fault, one learning-rate setting and two replay fractions, without tuning. Humanoid-v5 was not run: SAC's reported Humanoid learning curves span millions of steps~\cite{sac}, far beyond the 400,000-step source recipe, and our single workstation was at its memory limit. With eight seeds, exact tests cannot reach a family-wise 0.05 level in the primary family, so we rely on interval estimates. The critic diagnostic lies outside the pre-specified analysis, and the value-bias gap is exploratory. Evaluations use five deterministic episodes per condition and budget, and the controllers' differences in capacity prevent attributing their contrast to memory alone.
